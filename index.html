S3LabEdu

Tarefas de programação direto no Git da turma.

O professor publica um repositório; cada aluno recebe o seu fork, trabalha nele e entrega com um comando.

$ git clone …/sua-matricula/exercicio.git
$ entrega.bat
✓ Envio concluído no seu fork
